# Alibaba Sourcing Wiki

This wiki explains the settings that control how products are searched on Alibaba, how results are saved, and how they are scored.

- [Search Options](Search-Options.md): every setting that changes what is searched and what it costs.
- [Caching and PocketBase](Caching-and-PocketBase.md): where results are saved and what PocketBase stores.
- [Scoring Options](Scoring-Options.md): the filters and weights that rank vendors.

## The short version

1. You upload an Excel file of products you want to source.
2. The app groups similar products into families, so one Alibaba search covers many products.
3. Grouping is free. Searching Alibaba costs ScrapingBee credits and only runs when you confirm it.
4. Search results are saved, so the same search is never paid for twice.
5. Scoring uses the saved results only, so it is always free and can be repeated with different settings.
